# 日语修炼塔(N5→N1 闯关题库)设计文档

> 2026-06-25 · 基于已入库的 10,613 词(N5–N1,带词性 + 活用引擎)与 888 语法点,
> 设计一套趣味闯关玩法,把零散数据变成「从 N5 一路爬到 N1」的有爽感的学习系统。

## 1. 目标与核心概念

把庞大的词/语法数据组织成一座 **5 层修炼塔**(N5→N1),用 **闯关 + 多题型 + 星级 + 连击 + Boss 突破战** 驱动持续学习。
四个已确认的设计基调:
- **阶梯为主 + 追番加成**:主骨架是用全量数据构建的 JLPT 阶梯;看过的番剧场景里出现过的词/语法获得标记、优先出题与额外 XP。
- **模板为主 + LLM 调味**:题目以确定性模板生成(免费、秒出、无限),仅例句类用 LLM 并缓存。
- **闯关塔 + Boss 突破战**:每级一层,层内分区,区内小关,区末 Boss。
- **闯关=学,SRS=记,自动打通**:关卡里新接触/答错的词与语法自动进入现有 SRS 复习池。

## 2. 塔结构与推进

```
塔 = N5 → N4 → N3 → N2 → N1(顺序解锁)
每层 = 若干「区」(Zone)
每区 = 5 小关(Stage) + 1 Boss 战
每小关 = ~10 道混合题,覆盖该关 ~8 词 + ~2 语法
```

- **内容排序**:每层取该级别全部词(按 `Vocab.id`,≈ 导入顺序)与全部语法(按 `id`),顺序切分成区/关。确定性可复现。*词频排序列为后续增强(需补充词频字段)。*
- **小关流程**:答 ~10 题 → 按最佳一次正确率评星:**≥60% = 1★(通关)、≥80% = 2★、=100% = 3★**。可无限重刷刷星。
- **解锁**:小关在区内顺序解锁(过前一关解锁下一关);5 小关全过 → 解锁 Boss。
- **Boss 突破战**:该区全部词+语法混合 ~20 题,**≥80% 通过**才解锁下一区;失败可重来,**无红心、不惩罚**(单机自学定位)。
- **跨层解锁**:某层最后一个区的 Boss 通过 → 解锁下一层 N 级。

## 3. 题目引擎(4 题型)

所有题为四选一(选择/填空均以选项呈现)。干扰项取自**同级别**词/语法,保证难度合适。

| 题型 | 生成 | 题面 → 答案 | 干扰项 |
|---|---|---|---|
| 词义选择 | 模板 | 日语词 → 中文释义(及反向) | 同级别其它词的释义 |
| 读音选择 | 模板(仅含汉字的词) | 汉字写法 → 假名读音 | 同级别相近读音 |
| **活用填空** | **活用引擎** | 词 + 目标活用形(如「て形」)→ 正确形 | 该词的**其它活用形**(最易混) |
| 语法+例句填空 | 用法=模板;例句=LLM 缓存 | 语法点 → 中文意义 / 例句挖空选语法 | 同级别其它语法点 |

- 每个词条出题时,在「词义/读音/活用」中随机挑一种可用题型(活用仅对可活用词)。
- 例句填空复用现有 `grammar_quiz` 的 LLM+缓存模式(`GrammarPoint.quiz_cache`)。
- **题目不入库**,每次进关实时生成(模板瞬时;LLM 命中缓存)。

## 4. 追番加成(挂钩追番核心)

- **标记来源(复用现有数据,不加新列)**:`Vocab.source_line_id` 非空 = 场景里抽到的词 → 「📺 番剧词」;`GrammarPoint.status` ∈ {seen, learning}(管线已在标)→ 番剧语法。
- **效果**:番剧词/语法在出题时**优先排入早期关**;答对给 **1.5× XP**;卡片显示「📺」。
- **每日番剧挑战**:从最近看过的场景关联的词/语法抽 ~10 题,单独入口,接现有 streak。首页「今天」放一张挑战卡引流。

## 5. 与 SRS 打通(学→记闭环)

- 关卡里**首次接触**的词/语法 → 自动 `in_srs=true`,进入复习池。
- **答错**的词/语法 → 进 SRS 且 `due_date` 设为当天(尽快复习);复用现有 `services/srs.py` 与「复习页」。
- 闯关只负责"学与推进";长期记忆交给 SRS。两套不重复。

## 6. 游戏化激励

- **XP + 玩家等级**:答对得基础 XP(如 10);**连击 combo**——关内连续答对倍率 ×1 起、每连对 +0.1、上限 ×2;番剧词额外 1.5×。玩家累计 XP 映射玩家等级(轻量曲线,纯展示)。
- **星级**:每关 1–3 星驱动回刷;塔地图显示各关星数与总星数。
- **连续天数 streak**:复用现有 `DailySession`,每日完成任意闯关/挑战即续。
- 明确**不做**:红心/体力、段位天梯、排行榜(单机自学,惩罚与竞技无意义)。

## 7. 数据模型

新增:
- **`TowerProgress`**:`id, level(str), zone_idx(int), stage_idx(int), is_boss(bool), cleared(bool), stars(int 0–3), best_accuracy(float), attempts(int), updated_at`;唯一约束 `(level, zone_idx, stage_idx, is_boss)`。
- **`PlayerStats`**(单行):`id, total_xp(int), player_level(int), updated_at`。

复用现有:`Vocab`/`GrammarPoint` 的 SRS 字段与 `source_line_id`/`status`;`DailySession` 的 streak。
**关卡布局不入库**——由 `tower.py` 按固定切分规则从词/语法顺序确定性计算。

## 8. 架构(沿用现有分层)

**后端**
- `services/quiz_bank.py`:4 类题型生成器,输入词条/语法 + 同级别池 → 题目 dict。纯函数、可 TDD。
- `services/tower.py`:塔布局(level→zones→stages 的确定性切分)、进度查询、解锁判定、交卷结算(评星、算 XP、写 TowerProgress/PlayerStats、推 SRS)。
- `api/tower.py`:
  - `GET /api/tower` — 塔地图(各层/区/关 + 进度 + 锁状态)。
  - `GET /api/tower/stage` — 取某关题目(?level&zone&stage&boss)。
  - `POST /api/tower/stage/submit` — 交卷:答题结果 → 评星、XP、解锁、写 SRS。
  - `GET /api/tower/daily-anime` — 每日番剧挑战题目。
  - `GET /api/player` — 玩家 XP/等级/streak。

**前端**
- `pages/Tower.tsx`:塔/关卡地图(层切换、区/关节点、星数、锁)。
- `pages/Quiz.tsx`:答题界面(题干、四选项、即时对错、连击与星级动画、结算页)。
- 导航:主导航加「🗼 修炼塔」;「今天」加每日番剧挑战卡。
- `lib/api.ts` + `types.ts` 增对应封装与类型。

## 9. 测试策略(TDD)

- `quiz_bank`:每类题型的生成、干扰项不含正确答案、活用填空干扰项来自同词其它形、同级别取池。
- `tower`:布局切分确定性、解锁规则(关顺序/Boss 门槛/跨层)、交卷结算(评星边界 60/80/100、XP 与连击、番剧 1.5×)、SRS 写入(新词入池、错题 due 当天)。
- `api/tower`:地图、取题、交卷、每日挑战、404/边界。
- 前端:塔地图渲染与锁态、答题流程与结算、导航入口。

## 10. 范围与分期

- **v1(本期)**:塔结构 + 4 题型 + 星级/XP/连击 + SRS 打通 + 基础追番加成(📺 标记 + 优先 + 加成)+ 每日番剧挑战。
- **以后**:听力题(TTS 现成)、词频排序、Boss 花样与限时、实力测试跳级、错题本、成就/图鉴。

## 11. 关键决策回顾

| 决策 | 选择 | 理由 |
|---|---|---|
| 与追番关系 | 阶梯为主 + 追番加成 | 系统性 + 不失 App 灵魂 |
| 出题 | 模板为主 + LLM 例句 | 低成本、秒出、活用题独门 |
| 骨架 | 闯关塔 + Boss | 爽感 + 清晰推进 |
| SRS | 学/记打通,自动入池 | 统一闭环不重复 |
| 题型 v1 | 词义/读音/活用/语法+例句 | 覆盖面 + 突出活用引擎 |
| 关卡 | ~10 题/关,5 关+Boss/区 | 节奏适中 |
| 通过线 | 关 60%、Boss 80%,无红心 | 自学不惩罚 |
| 入口 | 主导航新 tab + 今天挑战卡 | 大功能值得显眼 |
